# conventions

How this project works, written down.

- `domain/` holds the standing assumptions, notation, glossary and what counts
  as an argument here. This is the context a collaborator would otherwise pick
  up over weeks of conversation.
- `meta/` describes how the repository itself works: naming, file conventions,
  attribution, and the recurring workflows.

An AI collaborator is permanently a new collaborator on their first day, and
this folder is the only thing it knows. Everything here is read at the start of
every session, so keep it short and keep it current.

Context that is wrong does more damage than context that is missing, because
the model will believe it. Prune as carefully as you add. Everything in
`domain/` was rebuilt from `paper/draft.tex` on 2026-09-04; when the draft
moves, these files move with it, not before.
