# sources

What was said, known or decided. Past tense, fixed.

```
papers/       works we cite or work from: source.md + paper.md extraction (+ pdf)
meetings/     discussions with collaborators, and harvested working sessions
decisions.md  the decision log, dated, append only
```

**Preserve files here as the record.** A correction goes in a synthesis, so
that the original and the correction both stay visible. The decision log is the
one file that grows: add lines at the end, never change earlier ones.

Naming is `YYMMDD - short description`, dated to when the thing happened or
first appeared. See `conventions/meta/naming.md`.

## Why sources and syntheses are kept apart

Keeping sources fixed and syntheses live is what stops an agent from reading
its own output back as evidence. If records and summaries sit in the same
place they become indistinguishable within months.
